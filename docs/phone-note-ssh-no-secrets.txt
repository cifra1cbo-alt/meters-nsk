# Постоянный доступ агента к серверу БЕЗ Cursor Secrets
========================================================

Заполните:
  SSH_USER = maxim (пример)
  SERVER_IP = ваш IP

Цель: агент всегда может зайти на сервер, без Secrets и без браузерного dashboard.

────────────────────────────────────
РЕКОМЕНДУЕТСЯ: Remote Control с Mac
────────────────────────────────────

Агент работает НА ВАШЕМ MAC (ключ уже лежит в ~/.ssh).
Телефон/веб только управляют этим Mac.

1) На Mac ключ должен быть:
   ls ~/.ssh/cursor_meters_nsk

2) Публичный ключ на сервере (один раз):
   ssh-copy-id -i ~/.ssh/cursor_meters_nsk.pub SSH_USER@SERVER_IP

3) Cursor на Mac → Settings → Agents → Remote Control → ВКЛ (ON)
4) Keep This Computer Awake → ВКЛ (ON), Mac от питания
5) С телефона открывайте того же агента / новый чат —
   он идёт через Mac, SSH на сервер работает постоянно

Плюсы: без Secrets, без dashboard, не «вылетает» после новой облачной VM
Минусы: Mac должен быть включён и не засыпать

────────────────────────────────────
Альтернатива: агент прямо на сервере
────────────────────────────────────

Если Cloud Agent / worker крутится НА самом сервере Timeweb,
SSH до Max не нужен — всё локально (docker exec, max list).

Это самый стабильный вариант для «Сервер Мессенджер Макс».

────────────────────────────────────
НЕ рекомендуется
────────────────────────────────────

• Класть приватный ключ в git
• Вставлять ключ в чат каждый раз
• Cursor Secrets — только если Remote Control неудобен

────────────────────────────────────
Проверка
────────────────────────────────────

На Mac:
  ssh -i ~/.ssh/cursor_meters_nsk SSH_USER@SERVER_IP "whoami && uptime"

В агенте (через Remote Control):
  ssh SSH_USER@SERVER_IP "whoami"
